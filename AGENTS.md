# Project Layout

This project is a single-file web app. Keep these files at the repository root:

- `AGENTS.md`: project instructions and folder layout
- `spec.md`: what the app should do
- `prompts.md`: prompt log
- `index.html`: the app entry point required by GitHub Pages

Use the numbered folders for all other project files:

- `00_planning/`: notes and sketches
- `01_data/`: data files
- `02_validation/`: hand calculations and test cases
- `03_output/`: screenshots and exported results

Save every new file in the appropriate folder above; keep the four listed
project files at the top level.
